# rbfx-blueprint brand assets

The official rbfx-blueprint identity combines a 3D cube, Blueprint graph nodes, and World Fabric connections.

## Official assets

| Asset | Intended use |
| --- | --- |
| `rbfx-blueprint-logo-symbol.png` | Primary standalone symbol for the engine, editor, documentation covers, and square branding contexts. |
| `rbfx-blueprint-logo-lockup.png` | Official horizontal lockup for the GitHub repository, README header, project pages, and light presentation surfaces. |
| `rbfx-blueprint-logo-dark.png` | Alternative horizontal lockup for dark application surfaces, splash screens, and editor presentation backgrounds. |
| `rbfx-blueprint-icon-512.png` through `rbfx-blueprint-icon-64.png` | Application icons and compact product surfaces. |

The GitHub repository uses `rbfx-blueprint-logo-lockup.png` as its primary presentation image, while the standalone symbol remains the canonical mark for square contexts.

## Palette

- Deep navy: `#08142B`
- Blueprint blue: `#1E80F4`
- Electric cyan: `#00DDFF`
- White: `#EEF6FF`

## Usage rules

Keep the symbol and lockup unobstructed, preserve their proportions, and do not recolor the artwork outside the documented palette. Use the horizontal lockup where the project name and descriptor must be immediately legible; use the standalone symbol where the available space is square or compact. Maintain sufficient contrast against the surrounding surface and do not place dense content over the artwork.
